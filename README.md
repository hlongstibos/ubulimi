# Ubulimi

Web app scaffold built with [Next.js](https://nextjs.org) (App Router), TypeScript and Tailwind CSS.

> _ubulimi_ — isiZulu/isiXhosa for "agriculture / farming".

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command         | Description                       |
| --------------- | -------------------------------- |
| `npm run dev`   | Start the dev server (Turbopack) |
| `npm run build` | Production build                 |
| `npm run start` | Serve the production build       |
| `npm run lint`  | Run ESLint                       |

## Project structure

```
src/
  app/            App Router routes, layouts and pages
public/           Static assets
```

## Deployment

Deploy on [Vercel](https://vercel.com/new) or any Node host that supports Next.js.
